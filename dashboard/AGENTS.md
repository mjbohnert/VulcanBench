# Writing conventions (applies to ALL output)

Never use em-dashes ("—", U+2014) anywhere: not in code, comments, commit
messages, docs, chat replies, or any other generated text. No exceptions.
Restructure instead: use a comma, a colon, parentheses, or two sentences. A
plain hyphen ("-") is fine for ranges and compound words. Avoid en-dashes ("–")
too; write "to" for ranges. See the repo root CLAUDE.md / AGENTS.md for the
canonical rule.
