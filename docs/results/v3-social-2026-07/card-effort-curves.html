One knob, four answers (what paying for effort buys)

Twenty-three real merged PRs across five languages, graded by deterministic hidden tests — each flagship run at low, medium, and high effort
Every provider ships the same knob: pay more, think harder. The four flagships answer it four different ways. Grok buys two tasks and plateaus. Sol climbs one task per step. Fable ends where it started. Opus 5 loses a task at every step — while its bill triples.
Figure 1. Tasks solved (of 23) at each effort setting. Suite cost beneath each point; dots darken low → medium → high.
Method. VulcanBench v3: 23 tasks from real merged post-cutoff PRs, network-isolated Docker sandboxes, deterministic hidden-test grading, one attempt per task per configuration. Grok, Sol, and Fable from Report No. 07; Opus 5 from Report No. 10. Opus 5’s high-effort losses are budget timeouts, not wrong answers — it returns the fewest wrong answers of any configuration. Kimi K3 and Haiku 4.5 ship a single configuration and are omitted.
